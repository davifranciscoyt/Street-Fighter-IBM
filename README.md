# Visão Geral

O SF2IBM é um projeto dedicado à preservação histórica, análise, restauração e documentação técnica da versão de Street Fighter II desenvolvida para a plataforma IBM PC/DOS por Jung Y.D. / Jung Young-dug.

O objetivo principal deste repositório é documentar e catalogar a estrutura interna do jogo, incluindo:

- Arquivos e executáveis;
- Formatos de dados proprietários;
- Recursos gráficos;
- Paletas de cores;
- Áudio;
- Personagens;
- Sequências e animações;
- Arquivos de configuração;
- Rotinas e estruturas relacionadas ao funcionamento do jogo.

---

# Finalidade do Repositório

Este repositório funciona como uma base de conhecimento técnico e histórico sobre o SF2IBM.

Para preservar a organização e a integridade do acervo, os materiais são classificados nas seguintes categorias:

Material Histórico/Original

Arquivos binários, documentos e recursos preservados da distribuição histórica original do jogo.

Material Restaurado

Elementos históricos que passaram por processos de recuperação, correção ou restauração técnica, procurando preservar o conteúdo original.

Material Modificado

Alterações, edições, experimentos e testes baseados nos formatos e estruturas originais.

Documentação

Manuais técnicos, especificações de arquivos, referências e guias descritivos.

Pesquisas e Análises

Estudos de engenharia reversa, análise de dados, estruturas internas, formatos proprietários e comportamento do software.

# Formatos de Arquivo

O projeto documenta especificações, cabeçalhos, estruturas de dados e possíveis relações entre os seguintes formatos:

Formato| Finalidade documentada
"CFG"| Arquivos de configuração do sistema e do jogo
"KEY"| Mapeamento de comandos e entradas de controle
"SEQ"| Sequências de quadros, frames e animações
"SDL"| Tabelas, comandos e estruturas associadas aos executáveis e personagens
"IDE" / "ID"| Identificação, índices e mapeamento de recursos
"RE" / "R"| Recursos, dados gráficos, sprites e faces/avatares
"MDI"| Dados associados a personagens, áudio e/ou sequências

Extensões de Personagens

Os arquivos relacionados aos personagens incluem:

.re
.ide
.sdl
.seq
.key
.mdi

# Tópicos Técnicos

A documentação do SF2IBM aborda diferentes componentes internos do jogo.

Personagens

Mapeamento de arquivos, recursos e estruturas de dados específicas utilizadas pelos lutadores.

Sequências e Animações

Estudo de:

- Frames;
- Ordem das sequências;
- Tempo de exibição;
- Transições;
- Estados de animação;
- Dados associados aos personagens.

Comandos

Documentação do sistema de entrada e do mapeamento de ações através de:

- Teclado;
- Joystick;
- Comandos dos personagens;
- Estruturas de controle.

Gráficos e Cenários

Análise dos métodos de armazenamento e utilização de:

- Sprites;
- Fundos;
- Cenários;
- Camadas gráficas;
- Recursos de personagens;
- Dados gráficos comprimidos ou estruturados.

Paletas RGB

Documentação das tabelas de cores e das paletas utilizadas pelo sistema gráfico do ambiente DOS.

Áudio

Estudo da estrutura e do carregamento de arquivos relacionados a:

- Sons;
- Música;
- Sequências de áudio;
- Dados associados aos personagens.

Configuração

Mapeamento dos parâmetros presentes nos executáveis e arquivos de configuração, incluindo arquivos ".cfg".

# Objetivos de Preservação

O projeto busca:

- Preservar arquivos e documentação histórica;
- Registrar informações técnicas antes que sejam perdidas;
- Estudar formatos proprietários antigos;
- Documentar estruturas internas;
- Facilitar pesquisas sobre software para DOS;
- Restaurar materiais históricos quando tecnicamente possível;
- Separar claramente conteúdo original, restaurado e modificado;
- Contribuir para estudos de retrocomputação e preservação de software.
